# CloudForge Modern Frontend

Modern responsive HTML/CSS frontend for the CloudForge DevOps learning project.

## Files
- `app/index.html` — website structure and small mobile navigation script
- `app/style.css` — responsive dark theme and styling

## Run locally
Open `app/index.html` in your browser, or serve the `app` directory with a local static web server.

The frontend is currently static; backend, database, and live deployment data can be added later.
